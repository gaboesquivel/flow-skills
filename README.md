# Flow Skills

An open-source Lean Startup methodology and agent skill set for solo founders and small technical teams. The methodology is being refined; skills are not yet implemented.

Start with [product direction](PRODUCT.md), then the [principles draft](docs/principles.md) and [methodology](docs/methodology.md).

Use the [documentation guide](docs/README.md) to find ideas, research, and decision records. The [reference index](docs/references.md) collects our sources; [AGENTS.md](AGENTS.md) governs work in this repository.

The [glossary](GLOSSARY.md) defines project-specific language. The [development initiative](docs/initiatives/methodology-and-skills.md) tracks how manual practice informs the future skills.
