# Jobs To Be Done

Start from a concrete situation: who is trying to make progress, what triggered the struggle, and what they hire a solution to do. Read existing context before asking questions; ask only when a missing detail would change the framing.

Describe the functional, emotional, and social dimensions only when they affect the decision. Contrast the current way people cope (including doing nothing) with the proposed direction. Keep scope tied to the user's stated decision, not a full market taxonomy.

Return a concise JTBD summary: job statement, forces pushing and pulling change, anxieties and habits that resist change, and non-goals. Distinguish evidence from inference.

This skill frames product intent; it does not authorize implementation. Optional [interview](../interview/SKILL.md) or [competitors](../competitors/SKILL.md) skills may extend the work when invoked separately.
