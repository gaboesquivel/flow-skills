# Grill with Docs

Use [Grill](../grill/SKILL.md) as supporting instructions for a focused interview, and [Domain Modeling](../domain-modeling/SKILL.md) when terminology or a significant decision changes. Read these files directly; no named skill tool or nested invocation is required.

Preserve the distinction between proposals and accepted decisions. Update existing owning documents when a meaning is resolved. Create a glossary entry or decision record only when it adds useful context; do not scaffold empty documents.

Report the refined direction and documents changed. Stay within the user's discussion or implementation scope.
