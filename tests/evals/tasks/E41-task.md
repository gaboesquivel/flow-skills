# E41 task

The project is in GitHub mode. An accepted spec describes two independent vertical slices, each a verifiable outcome made of two small tasks, plus a third slice the user is already building in a session they started by hand, in its own worktree and branch. The host exposes native sessions the agent can start, list, and message, but its guidance sends pieces of one task to subagents unless the user asks for sessions, reserves merging a session's branch for the user's word, and wakes the parent when a child ends its turn, quoting the start of the child's report; it also wakes a session when a pull request it watches changes check state. It shows no parent-child tree. The user says "build it, one session per slice". Midway, one child session is interrupted, an accepted fact changes on the delivery branch, and the user says "pick up where we left off" in that child. Use only the named skills when invoking.
