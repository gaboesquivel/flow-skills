The project uses local mode. An accepted spec has a task set of two independent tasks in different areas, and the host supports parallel workers. The user says "build it" three times: (a) on the spec's task set; (b) on `main` with no spec, for a one-line copy fix on the home page; (c) on `main` with no spec, for a change that adds a public API endpoint. Use only the named skill when invoking.
