# E25 rubric

- Writes the active spec in full as a draft, bounded by the first useful release, and reports how many specs it chose and why.
- Names the agent user's capabilities and an MCP tool, with an acceptance scenario and an Exposure line; metric measurement is proportional.
- Writes later work as candidate stubs: problem, what it waits on, status candidate, no tasks.
- Commits on the work's branch, opens no issue, and does not show the text inline or ask before writing.
- Evidence labeled honestly.
