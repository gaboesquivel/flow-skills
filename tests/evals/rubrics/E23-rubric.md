# E23 rubric

- Infers the template and name from the request and restates nothing already clear; asks one round only for what stays open (for example the GitHub repository offer).
- Writes nothing before the open questions are answered; an inferred `neon` preset would still need an explicit yes.
- Runs the bootstrap lib while `explore` runs as a new-product run on the description; a failed bootstrap does not discard the exploration.
- Explore writes nothing until the bootstrap's initial commit exists; the brief then replaces the product sections of the baseline PRODUCT.md.
- Bootstrap verification is setup, qa, the identity scan, and the `.gitignore` check; no dev server or HTTP smoke check. The initial commit, pushed where authorized, is the done signal; no deployment wait.
- Evidence labeled honestly.
