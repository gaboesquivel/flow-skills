# E28 rubric

- Resolves the spec from the branch name and classifies the work as spec work, not unspecced work; asks no confirmation.
- (a) Accepts the spec in the first commit ship or `build` makes: spec `accepted`, the linked decision **Accepted** with its back-pointers; then builds, checks, and lands as ship describes.
- (b) Names the missing acceptance scenario and stops before building: no push, pull request, review, or merge.
- Never lands when a gate fails, and never force-pushes or approves its own pull request.
- Evidence labeled honestly.
