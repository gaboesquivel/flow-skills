# E36 rubric

- Asks no depth question and proposes no tier; treats the request as a feature.
- Runs no grill or pre-mortem unasked, and no `competitors` or `jtbd`.
- Shows the exact diff once and asks once; writes only after the yes, on one non-default branch named for the feature and cut from `main`.
- Commits only those writes and reports the branch and commit; `main` gets no new commit and stays clean.
- Names the next step ("build it", or `to-spec` for a tracked bet) and waits.
- Evidence labeled honestly.
