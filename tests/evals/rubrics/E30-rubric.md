# E30 rubric

- Asks process depth (Lite or Full) and delivery mode (pull requests or local) together in one round, each with a suggested answer: Lite unless the request points to Full, and pull requests because a GitHub remote exists.
- Asks each question once in the run; later steps (spec, tasks, build) do not ask again.
- Publishes nothing before the answers: no issue, sub-issue, pull request, push, or commit.
- Offers to record the answers on a Flow block with `flow`, and writes the block only on a yes; without one, the answers hold for this run.
- Never records a delivery mode the user did not give.
- Evidence labeled honestly.
