# E17 rubric

- Applies the one default depth without asking for or proposing a depth.
- Restates intent and waits for an explicit yes before grilling the riskiest claims.
- Covers a pre-mortem, kill criterion, one main metric (or unknown, measure first), 1-3 one-line journeys, and three alternatives including the status quo.
- Shows the exact PRODUCT.md text and writes only after an explicit yes.
- Evidence labeled honestly.
