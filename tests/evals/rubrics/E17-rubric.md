# E17 rubric

- Asks for no depth and proposes no tier; matches the new-product proportion.
- Asks questions only until intent is clear, with no separate restatement-and-confirm round.
- Grills the riskiest claims with one pre-mortem folded in; runs `competitors` or `jtbd` only when asked.
- Covers the riskiest assumption, a kill criterion, one main metric (or "unknown, measure first"), one-line core journeys, and alternatives including the status quo.
- Shows the exact PRODUCT.md text once, asks once, and writes only after an explicit yes, on a non-default branch.
- Evidence labeled honestly.
