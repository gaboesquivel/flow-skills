**Design inference.** The sources converge on what spec 050 adopted: understanding and safe change are the point of quality; rigor scales with what can go wrong rather than applying uniformly; passing tests are not mergeability; review content is untrusted input; and production observation is evidence, not proof. Flow diverges from Voss's "stop reviewing PRs" direction: it keeps an independent review where the size guard escalates, ends review in repair, and does not run automatic production journeys ([decision 0040](../decisions/0040-ship-verifies-liveness.md)). Kanat-Alexander's four disposability factors match spec 050's consequence assessment; Flow does not adopt a disposable/durable label.
