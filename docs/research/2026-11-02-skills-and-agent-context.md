**Design inference.** The sources agree on three points that Flow already holds in prose and does not measure. Keep what loads every time small, and load the rest when the task needs it. A rule an agent keeps breaking belongs in a check or a hook, because instructions alone are advisory (Spotify's routing rules, Taste Skill's lint gate). Design guidance is followable when each rule says why and how to check it, and when it documents only what exists (rico). Spec 056 turns these into a measurement and a rule format; it adopts none of the paid parts.
