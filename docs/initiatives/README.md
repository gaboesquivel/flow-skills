Adopting a capability or documenting an idea does not automatically start an initiative.

An initiative needs enough context to explain its purpose, boundaries, consequential assumptions, planned work, and how findings inform the next decision. Link relevant ideas, evidence, and decisions rather than copying them. Tasks inherit this context and need not repeat the validation exercise.

The file format, status conventions, task tracking, and relationship to the future validation board remain open. This is not a required template for every change.
