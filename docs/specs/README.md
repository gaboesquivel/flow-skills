# Specifications

Numbered specifications describe a bounded increment of work: product, research, marketing, engineering, or cross-functional.

Default path: `docs/specs/NNN-short-name.md` (three-digit sequence, kebab-case slug). Choose the next free number from existing files. Projects with an established convention keep it.

Examples in this repository: [001-portable-skill-catalog.md](001-portable-skill-catalog.md), [002-flow-lite-and-flat-docs.md](002-flow-lite-and-flat-docs.md), [003-flow-templates-baseline-v2.md](003-flow-templates-baseline-v2.md) (historical template baseline), [004-pr-alignment-review.md](004-pr-alignment-review.md), [005-flow-templates-interop.md](005-flow-templates-interop.md) (current template interoperability target), [006-skill-reliability.md](006-skill-reliability.md).

Significant standalone decisions belong in `docs/decisions/`, not in a spec. See [decisions](../decisions/README.md).
