# Specifications

Numbered specifications describe a bounded increment of work: product, research, marketing, engineering, or cross-functional.

Default path: `docs/specs/NNN-short-name.md` (three-digit sequence, kebab-case slug). Choose the next free number from existing files. Projects with an established convention keep it.

Examples in this repository: [001-portable-skill-catalog.md](001-portable-skill-catalog.md), [002-flow-lite-and-flat-docs.md](002-flow-lite-and-flat-docs.md), [003-flow-templates-baseline-v2.md](003-flow-templates-baseline-v2.md) (historical template baseline), [004-pr-alignment-review.md](004-pr-alignment-review.md), [005-flow-templates-interop.md](005-flow-templates-interop.md) (current template interoperability target), [006-skill-reliability.md](006-skill-reliability.md), [007-catalog-skill-restoration.md](007-catalog-skill-restoration.md), [008-tasks-and-domain-modeling.md](008-tasks-and-domain-modeling.md), [009-flow-mode.md](009-flow-mode.md), [010-explore-redesign.md](010-explore-redesign.md), [011-start-with-explore.md](011-start-with-explore.md), [012-progress-board.md](012-progress-board.md) (draft), [013-consolidation.md](013-consolidation.md), [014-faster-pr-ci.md](014-faster-pr-ci.md), [015-wave-checkpoints.md](015-wave-checkpoints.md), [016-process-depth.md](016-process-depth.md), [017-build-and-ship.md](017-build-and-ship.md), [018-spec-issues.md](018-spec-issues.md) (draft).

Significant standalone decisions belong in `docs/decisions/`, not in a spec. See [decisions](../decisions/README.md).
