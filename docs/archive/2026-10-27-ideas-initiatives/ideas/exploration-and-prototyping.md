# Exploration and disposable prototypes

Status: Adopted flexibility; `explore` skill shipped; disposable prototype skill deferred.

Retain spontaneous brainstorming, evidence-seeking exploration, and disposable UI or logic prototypes. The [`explore`](../../../../skills/explore/SKILL.md) skill covers repository and problem context before planning; it does not authorize implementation. A dedicated prototype skill is not in the current twelve-skill catalog ([0004](../../../decisions/0004-portable-skill-catalog.md)).

Sources and current home: [Principles](../../../principles.md#room-for-exploration); [historical exploration and prototypes](../../../archive/2026-10-18/docs/ideas/2026-10-18-exploration-and-explanation.md).

The [Lean UX assessment](../../../research/2026-10-20-lean-ux-and-startup-canvas.md#lean-ux-connect-experience-choices-to-learning) adds candidate approaches for connecting experience alternatives to user outcomes and decomposing assumptions into useful tests. Its mandatory workshops, cadence, and scoring are not adopted.

On 2026-10-20, the user adopted the distinctions between exploration, research, and intent in [GLOSSARY.md](../../../../GLOSSARY.md#exploration), alongside the existing idea and initiative meanings. Initiative remains the term for intentional work; intent describes its purpose. The [origin discussion](../../../research/2026-10-20-prd-structure-exploration.md#exploration-research-ideas-and-intent) preserves the rationale. Skill boundaries remain open; potential differentiation is a hypothesis, not an established advantage. These distinctions add no required sequence or artifact.
