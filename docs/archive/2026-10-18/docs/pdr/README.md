# Product Decision Records

- [0001 — One refinement entry with distinct focuses](0001-focused-refinement.md) — accepted 2026-10-18.

Use a record for a significant product or experience decision whose rationale should survive the current conversation. Keep ordinary clarifications in the affected living document.

Provisional naming: `0001-short-decision-name.md`.

A useful record contains status (proposed, accepted, rejected, or superseded), date, context and evidence, decision, alternatives, consequences, and links to affected documents. Record acceptance evidence when a decision is accepted. A replacement should link the earlier record so its history remains understandable.

Accepted product decisions update PRODUCT.md; shared experience conventions update DESIGN.md when affected. The record preserves rationale; the living documents describe the resulting current position.
