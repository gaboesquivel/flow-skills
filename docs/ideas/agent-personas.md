# Agent personas as early product reviewers

Status: exploring. No skill implementation committed.

Use different personas and models to exercise an application and provide early feedback. Candidate for a future skill; naming, methods, and evaluation are open.

Proposed approach: assign realistic tasks, record observed interactions and failures, and retain model/persona details so findings can be inspected. Distinguish actual task execution from imagined reactions. Simulated feedback can inform hypotheses and detect issues; it does not independently validate human demand or willingness to pay. When agents are intended users, completed agent tasks can provide evidence of agent usability, not automatically commercial viability.
