# Business discovery and product metrics

Status: OMTM concept adopted on 2026-10-20; skill boundaries remain exploring. No skill implementation committed.

Explore optional strategic capabilities within Flow's existing discovery and learning loop. Proposed boundaries:

- `business-discovery`: initially consider an optional focus within product discovery; a separate skill would need recurring standalone use.
- `product-discovery`: candidate entry point for connecting business intent, customer opportunities, and tests. Resolve overlap with initiative refinement before defining it.
- `product-metrics`: candidate specialist skill for metric definitions, instrumentation planning, and interpretation. Basic outcome selection should remain available during discovery.
- Experimentation: consider a shared practice across discovery and reviewing outcomes rather than a separate skill.

These boundaries are assistant recommendations preserved for evaluation, not adopted skill specifications. Separate a skill only when it has a distinct trigger, useful standalone work, and a clear handoff. See [research and rationale](../research/2026-10-19-productskills-and-lean.md#business-context-growth-and-skill-boundaries); [PRODUCT.md](../../PRODUCT.md#business-context-and-measurable-outcomes) owns the current product direction. No implementation is authorized by this note.
