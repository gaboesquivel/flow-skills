# Writing for humans and agents

Status: two skills adopted on 2026-10-19; implementation remains open. Current commitment: [PRODUCT.md](../../PRODUCT.md).

The names identify the intended reader: `writing-for-humans` and `writing-for-agents`. The user requested both capabilities and identified Factory's human-writing and Matt Pocock's writing-for-agents as references. See the [source assessment](../research/2026-10-19-writing.md).

## Proposed boundaries

- `writing-for-humans`: draft and edit product copy, documentation, and communications for their audience and purpose. Preserve meaning and the author's voice; favor concrete, readable language.
- `writing-for-agents`: draft and edit skill instructions, agent guidance, and supporting context so agents can find relevant information, act on it, and recognize completion.

Shared project documents can serve both audiences. Apply both perspectives to the same authoritative content when useful; avoid maintaining duplicate versions solely for different readers.

On October 20, progressive disclosure and concise task-specific documentation were adopted as [current practice](../methodology.md#write-context-for-agents-and-humans). This does not adopt every upstream rule or implement either skill.

## Open choices

These capabilities span product and engineering. Category placement, invocation rules, evaluation, and the extent of upstream reuse remain open. The references inform design; their full rules are not automatically adopted. No skill implementation is authorized by this note.
